# About this folder

This folder is the **coding journal** for the Naan Kabob apps — the story of
what was built, what was decided, and what went wrong along the way, written
in plain language.

It lives in two places at once:

- **The master copy** is in the project's code repository on GitHub, in a
  folder called `notes/`. Claude updates it during coding sessions.
- **The copy you're reading** (if you're in Obsidian) is a mirror that your
  computer refreshes automatically about once an hour.

## One important rule

**Don't edit these notes here in Obsidian.** The sync is one-way — from the
project to your vault — so anything you type into these files will be
overwritten on the next refresh (within an hour). If you want something
added, changed, or remembered, just tell Claude in a coding session and it
becomes part of the master copy.

Notes you create yourself in *other* folders of your vault are completely
safe — the sync only touches this one folder.
